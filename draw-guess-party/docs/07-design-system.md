# 視覺設計系統

## 設計方向

白色背景為主，走「蠟筆/馬克筆手繪」語彙，貼合「畫圖」這個主題本身的材質感——不是把猜歌專案的介面原封不動搬過來，而是共用其「線上模式」的資訊架構概念（建立/加入房間分頁、房間代碼、玩家清單、聊天室），視覺表現改用這個專案自己的手繪筆觸風格。

簽名元素：卡片與按鈕統一用「2px 墨線外框 + 偏移實色陰影」（`--shadow-sm` / `--shadow-md`），取代常見的模糊漸層陰影，按下時陰影收回、元素位移，做出實體卡牌/貼紙般的觸感回饋。畫筆調色盤延伸同一語彙，16 色排成蠟筆盒式的格狀排列，選取時做出微幅旋轉/縮放的手感細節。

## 色彩 Token（定義於 `app/globals.css` 的 `:root`）

| Token | 色碼 | 用途 |
|---|---|---|
| `--ink` | `#1A1A2E` | 主要文字、外框線 |
| `--ink-soft` | `#4B4B63` | 次要文字 |
| `--paper` | `#FFFFFF` | 背景、卡片底色 |
| `--line` | `#E8E8F0` | 分隔線、底紋圓點 |
| `--accent` | `#FF6B4A` | 主色（珊瑚橘），主要按鈕、進行中狀態 |
| `--accent-soft` | `#FFE4DC` | 主色的淺色背景（例如輪到自己畫圖時的提示卡） |
| `--blue` | `#4C6FFF` | 輔色，加入房間相關操作 |
| `--green` | `#2ECC71` | 成功／猜對狀態 |
| `--amber` | `#FFB627` | 警示／公布答案卡片 |
| `--red` | `#E63946` | 錯誤狀態 |

## 字體

刻意不使用自訂 Web Font（Google Fonts 等）：這個開發環境的網路白名單不含字型 CDN 網域，強行引入會在建置或執行期失敗。改用系統 CJK 字型堆疊（`-apple-system, 'PingFang TC', 'Microsoft JhengHei', ...`），以字重（900/800/700）與字級對比做出標題與內文的層級差異。若之後要換成自訂字型，建議改用可自我託管的字型檔案（放進 `public/fonts/`），而非依賴外部 CDN。

## 共用元件類別（`app/globals.css`）

- `.dg-card`：白底、2px 墨線外框、偏移陰影
- `.dg-btn` / `.dg-btn-primary` / `.dg-btn-ghost` / `.dg-btn-block`：按鈕變體
- `.dg-input`：輸入框，統一外框粗細與 focus 樣式
- `.dg-tag`：膠囊狀標籤（房主標示、分類標籤等）
- `.dg-eyebrow`：小標籤文字（頁面頂端的分類提示，例如「線上模式」「管理後台」）

新增頁面或元件時，優先重用這些類別，避免每個元件各自寫一套內聯樣式造成視覺不一致。

## 遊戲關鍵通知的視覺系統

`components/room/StatusIcon.tsx`、`components/room/StatusOverlay.tsx` 是所有「遊戲關鍵通知」（遊戲尚未開始、選題中、等待對方選題、公布答案、比賽結束、錯誤訊息）共用的視覺外殼，統一版型為「圖示 + 標題 + 內容」：

- `StatusIcon`：手繪線條風格的圓形圖示，跟畫布筆刷、卡片外框走同一套「馬克筆」語彙（粗線條、圓角端點），全部用內聯 SVG 手刻，沒有安裝任何圖示套件（這個開發環境連不到圖示 CDN）。目前有 `clock`（等待）、`pencil`（選題）、`eye`（等待別人選題）、`megaphone`（公布答案）、`trophy`（比賽結束）、`alert`（錯誤）六種
- `StatusOverlay`：疊在畫布上的通知卡片外殼，固定「圖示置中 + 大標題（21px/900）+ 內容區」的版型，圖示底色依語意區分：等待類用 `--blue`、需要動作用 `--accent`、成功/公布用 `--green` 或 `--amber`、錯誤用 `--red`

新增任何「打斷使用者、需要特別注意」的通知時，優先用這兩個元件組合，不要另外手刻一套疊層樣式。
